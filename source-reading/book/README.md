# 成书：把章节 markdown 编成一本能读的 HTML 书

阶段三写完的章节是 markdown，能读但不好读。这个构建器把它们编成一本带封面、目录、正文与封底的静态书，双击 `index.html` 就能看，也能直接传到任何静态托管上。

---

## 三步

```bash
pip install markdown

cp book/book.config.example.json book.config.json   # 改成你这本书的信息
python3 book/build_book.py                           # 默认读 ./book.config.json
open dist/index.html
```

构建器会打印每章的引用数、图数、汉字数，最后给出总计。

想先看效果，仓库里带了一份现成的三章样张，原料和配置都在 `sample/`：

```bash
python3 book/build_book.py --config sample/book.config.json
```

它输出到 `docs/`，也就是[在线样张](https://itshen.github.io/source-reading-methodology/)那个站点目录。改完主题跑一遍这条命令，样张跟着更新。配置里的相对路径以配置文件所在目录为基准，所以那份配置的 `out` 写的是 `../docs`。

## 配置

```json
{
  "title": "书名",
  "subtitle": "一段话说清这本书回答哪个问题",
  "kicker": "源码精读",
  "author": "作者",
  "repo": "https://github.com/owner/repo",
  "anchor": { "commit": "4f39251a01", "tag": "course-anchor-20260822", "date": "2026-08-22" },
  "accent": "#3f4a5a",
  "chapters": "chapters",
  "out": "dist"
}
```

`repo` 与 `anchor` 是被精读的那个仓库和它的版本锚点，会印在封面和封底。读者据此判断书里的行号还作不作数。

`accent` 换一个色值就换一套配色，其余颜色都是从它推出来的。

## 输入要求

章节 markdown 放在一个目录里，按文件名排序就是章序。每章的开头这样写：

```markdown
# 第 1 章：章节标题

> 源码核对基于 owner/repo commit `4f39251a01`（2026-08-22），tag `course-anchor-20260822`
> 摘要：目录里显示的一句话，不写就自动取「场景还原」的头一句
```

`#` 是章名，紧跟的引用块是这一章的元信息，会排在标题下面的小卡片里。标题里的「第 N 章：」在版面上会自动去掉，因为章序单独排。

正文里的三种围栏各有对应的排版：

| 围栏 | 出来是什么 |
|---|---|
| ` ```153:160:path/to/file.rs ` | 带真实行号栏的源码引用块，可复制、可逐段步进 |
| ` ```mermaid ` | 图，进入视野时才渲染，带描线动画 |
| ` ```rust ` 等普通语言 | 普通代码块 |

每章末尾的 `## 交付自查` 默认不收进书，那是写给制作方看的过程记录。要留就加 `--keep-selfcheck`。

## 行号是怎么排的

这是这个构建器唯一需要解释的地方。

引用块头部声明了 `153:160`，块里如果没有省略，就从 153 一路往下数。**如果中间有省略标记，省略之后的行号是推不出来的**：省略跳过了多少行只有源文件知道。

所以：开头那段从声明的起始行正着数，结尾那段从声明的结束行倒着数，夹在两个省略之间的段落一律留空显示 `·`。宁可不显示，也不显示一个编出来的行号。

带省略的引用块头部会多一个「逐段」按钮，点一下按连续段依次高亮，让读者看清哪几行在源文件里真的连在一起。

省略标记的判据是：整行是注释，且注释符号后面紧接着就是 `...`。

```
    // ... 填 SID 表 ...        ← 是省略标记
    // 处理 bash -lc "..." 的情况   ← 不是，这是正常注释
```

这条判据比「注释行里含 `...`」严。宽判据会把源码里正常的文档注释误当成省略，那些行就不会参与逐字节比对，等于留了一个校验盲区。构建器遇到「没有省略、但行数和声明的区间对不上」时会打印提示，那通常意味着引用头部的起止行写错了。

## 书里有什么动效

都为可读性服务，不为炫技。开了系统的减少动态效果偏好会自动全部关掉。

- 顶部阅读进度条
- 正文分块滚动渐入
- 侧栏目录跟随高亮，点击跳转
- 引用块逐段步进，复制按钮
- 图进入视野才渲染，边线描出来
- 封面数字滚动
- 深浅色切换，记住选择
- 左右方向键翻章
