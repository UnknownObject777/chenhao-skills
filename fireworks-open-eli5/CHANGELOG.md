# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-08-24

Initial open-source release candidate:

- four evidence-aware story grammars: concept, module, tradeoff, and incident;
- deterministic, self-contained offline HTML rendering and validation;
- desktop SVG and dedicated mobile flow;
- global and scene-local playback with viewport following;
- scene-local source basis, evidence scope, failure lens, and teach-back;
- opt-in browser-local history, favorites, and plain-text annotations;
- PDF, PNG, PPTX, DOCX, and verified native Pages export paths;
- bilingual project documentation and interaction-language delivery reports;
- the selected A2 owl identity with README, avatar, and favicon-size assets;
- dependency-free Node.js tests, release-package checks, offline package canary,
  and an isolated Codex/Claude Code Agent Skills CLI install canary in CI.
